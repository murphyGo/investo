# u178 Tech decisions

Pure HTML escaping via html.escape for text/attributes; HttpUrl for source links. Existing neutral public quality projection applies only appropriate narrative/diagnostic strings, not exact price/time/source values. Structural HTML and existing build-time Markdown preserve paired asset URL rewriting. No runtime Markdown library. Existing E1→E2→trust gates→E6 transaction owns supplements and failures.

Separate NFR Design SKIP: focused requirements define representation, budgets, failure and region integration without a new architecture/storage model. Infrastructure SKIP: MkDocs/Pages unchanged. Renderer and site hook tests plus actual terminal malicious numeric/link cases validate that HTML is not a trust-gate bypass. Full program regression runs after final unit.

Escaped HTML entities are decoded once only inside existing anchor predicate/core-fact keyword evaluation. Canonical raw line/sentence/offsets and region ownership remain unchanged. The renderer→E1 supplement→terminal/E6 test rejects an unsupported S&amp;P claim while valid siblings seal; existing trust-block/optional omission decisions remain unchanged. This is a focused existing gate fix, not a new projection or validator registry.
