# u165 business logic

Resolve canonical SourceSpec defaults and exact operator enable/disable lists before source I/O. Registered provenance/name/routing remains44. Disabled adapters emit skipped with a bounded reason and make no request. Enabled adapters run through the existing timed failure-isolating collector. News-window holds preserve their existing separate semantics; a disabled adapter cannot emit full observation coverage.

Naver collects two markets concurrently. All child source errors produce one source failure; any valid child response (including genuine empty) remains distinguishable and valid items survive. Programmer exceptions propagate. Partial error diagnostics expose counts only.

BEA calls its existing three series under one60s adapter deadline, passing remaining budget to shared retry. Valid completed items survive later child error or timeout. If no request completed successfully and any error/expiry occurred, emit failure. Valid empty Data arrays produce zero. Malformed API envelopes are failed rather than silent empty; invalid rows are counted/excluded without publishing raw payloads.

Public badges/cards, Step Summary, history and digest preserve configured and skipped reasons while excluding skips from attempted denominators. Skips never count as core freshness, successful macro evidence, body-used evidence or completed event/news collection.
