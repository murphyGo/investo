# 비기능 및 수용 계약

- FR-001/002, US-008, u43/u66, NFR-002/003/004 및 R8/R10/R13을 따른다.
- Coin Metrics 무료 Community 무키 endpoint만 사용한다. bounded retry, 64KiB 응답·16행 상한. 기존 순유입 adapter와 실패 경로를 분리한다.
- 비상업 CC BY-NC 4.0·출처·Investo 평균 계산을 표시한다. 원천 상태값 미제공을 고지하고 확정/실시간/사용자 수/과거 공표본으로 표시하지 않는다.
- 조회 기간은 cutoff 이전 완료 UTC 일자만 포함한다. 최신 관측 신선도, 숫자 형식, 미래·중복 충돌, 부분 결측, 0 평균, 부족한 비교 표본을 검증한다. 실측 원 값은 공개 fixture에 저장하지 않는다.
- EF 권리 및 KRX 연간 근거가 부족하면 해당 범위를 미승격으로 남긴다. 사용자 적용 승인을 제공자 사용 허가로 해석하지 않는다.
- 독립 코드 리뷰, source/model/publisher/numeric/routing 회귀, 전체 정적 검사와 필요한 회귀를 완료한다. 공유 작업공간의 다른 세션 변경은 baseline 대조 후 보존한다.
