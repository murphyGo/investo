# 우선순위별 데이터 확장 설계

2026-10-30 KST. 사용자 “우선수위별로 적용하자” 승인에 따라 u66 활동 지표, EF 도입 자격, u43 위클리 순서로 진행한다. 단계별 승인을 반복하지 않는다.

1. Coin Metrics: 별도 `coinmetrics-network-activity` adapter, BTC·ETH × 활성 주소·거래 건수. 완료된 UTC 8일을 한 번 조회, 최대 16행. 최신 유효 관측은 최근 3일 이내. 지표별 결측·충돌을 격리하고, 직전 7일이 모두 유효할 때만 평균을 표시한다. 수수료·사용자 수·가격 방향 추론은 제외한다.
2. `NetworkActivity` 모델은 18자리 이하 비음수 정수 문자열과 관측일·수집 시각·대상 cutoff·0개 또는 7개 비교 표본을 검증한다. API가 주지 않는 검토 상태·공표 시각을 만들지 않는다. 조회된 현재 버전이며 역사적 vintage 증거로 사용하지 않는다.
3. source의 flat metadata에서 값과 평균을 재구성해 legacy/native 시황에 표시한다. 모델이 제공한 native 패널은 finalizer에서 대체한다. 숫자 검증 예외는 검증된 입력으로 만든 정확한 활동 표 행에만 적용한다. 정상 USD 가격과 변조 주장은 계속 검사한다.
4. EF: 공식 RSS의 사용·보존 범위를 확정하지 못하면 공개 source를 추가하지 않는다. 같은 데이터의 다른 페이지 라이선스를 가져오거나 동의되지 않은 본문 보강을 만들지 않는다. 막힌 조건을 자격 문서로 남긴다.
5. KRX: 공식 연간 공휴일과 거래소 규칙으로 지원 연도를 확정한 뒤 월물/월요일 위클리/목요일 위클리를 구분한다. 월요일 휴장은 뒤로, 목요일 휴장은 앞으로 조정하고 둘째 목요일 위클리를 제외한다. 표시용 2개는 월물 우선 후 가까운 위클리로 선택한다. 미지원 연도는 생성하지 않는다.

공통 등록: `sources/__init__.py`, `_internal/source_specs.py`, registry/plugin/lifecycle tests. KRX는 기존 lookahead 등록을 재사용한다. u182/u183 dashboard 저장 권한이나 운영 모드 변경은 이 확장에 포함하지 않는다.
