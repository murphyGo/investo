## Decision

The operator-owned `HF_DATA_API_KEY` is valid and usable from GitHub Actions. The current live
contract is not the daily JSON/CSV row contract assumed by the 2026-07-22 design:

1. Authentication is `X-API-Key`. `Authorization: Bearer` returns 401.
2. Daily data uses `GET /download-token/{ticker}` followed by a same-host, ten-minute signed
   URL whose payload is `application/octet-stream` Parquet.
3. The documented `timeframe=daily&format=csv&version=clean` combination returned 404 for SPY,
   while `daily+parquet` returned 200. The implementation may not assume CSV availability.
4. SPY plus all ten supported sector ETFs returned valid same-as-of daily series. XLRE returned
   404 from both public symbol metadata and the authenticated token endpoint.
5. Every successful file stayed below the existing 2 MiB/10,000-row per-response envelope.
   The operator approved the bounded signed-Parquet amendment with `gogo` on 2026-09-02, so
   Step 1 may proceed under the amended contracts.

The public product premise is unchanged: current rows are an IEX venue sample, XLRE remains a
value-free unavailable card, venue volume stays excluded from rank/regime/summary, and HF/IEX
attribution remains mandatory.
