# u176 Domain entities

No persisted data or Python DTO introduced. PageKind is the template-local closed set home/article/reference, derived from the actual src_uri. ThemeScheme is existing Material default/slate body attribute; the browser adapter never calculates financial/status data. HeaderControl references the existing for-target input and accessible action name. PageContent is unchanged `super()` output; wrapper/id provides scope and skip target. CSS tokens are presentation-only immutable per scheme. u177 classes are the exact consumer interface; no private runtime/source coupling.
